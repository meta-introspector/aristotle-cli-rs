Three Components

  1. Lean Specification & Oracle — RequestProject/Hodge/ holds the verbatim repository contract (HodgeComputer.Verify, Spec.lean), a computable sparse-polynomial checker over ℚ (runChecks, Check.lean / Oracle.lean, runs with #eval), and the theorem HodgeOracle.check_sound: if every Boolean check passes, Verify holds for the interpreted polynomials. Proved without sorry; axioms propext, Classical.choice, Quot.sound.
  2. HVM (Hodge VM) — A compact Rust VM compiled to WebAssembly (vm/, 45,563 bytes, sha256 777b4204a1249cc51ce836d5c4740bb23b25ff1c1b50dec796f212aedd15c6ab): sparse polynomials in six variables with exact big-rational coefficients, instructions LOADPOLY, ADD, SUB, MUL, SMUL, POW, PDERIV, DIR, DIV, EQ, ISZERO, ISHOM, DEG, EVALMOD, REPORT, … (see spec/isa.md), step and memory limits with clear errors, MiniLean report convention (claim k → (k,1) / (k,0)).
  3. Differential Testing — Ties the two together: WASM VM, a JavaScript reference VM, the Lean oracle and an independent Python fractions checker agree on all golden vectors.

v1 Scope (Shipped)

Core Build

lake build builds Spec, SPoly, Check, Oracle, Golden, Literal (a few minutes once Mathlib is cached). The 41 per-instance certificate modules (RequestProject/Hodge/Instances/) are a separate library HodgeInstances, not in the default build, so a slow instance can never break the core build.

Instance Builds

Instances are built one at a time, smallest first, with hodge-vm/tools/build_instances.sh [timeout] [Module ...]; results go to tests/instance-build-status.tsv. Current status: 39 of 41 kernel-checked (14 s – 386 s each); Contact46006 (147 KB) and M3Coupled (190 KB) are not kernel-checked yet. Failures and timeouts are recorded, not fatal.

Axiom Audit

#print axioms on the witness theorem gives exactly propext, Classical.choice, Quot.sound for all 39 kernel-checked instances — 34 via tools/axiom_audit.sh and the 5 largest one module per run via tools/audit_one.sh.

No native_decide

No native_decide anywhere in anything described as proved — it adds an axiom the repository's verifier rejects. The core soundness theorem HodgeOracle.check_sound uses propext, Classical.choice, Quot.sound only.

Layout for Small Models

Every page is ≤ 20,000 estimated tokens (3 characters per token; checked by tools/chunk_check.py). The two largest instances are split into part modules P1…P5 to fit. INDEX.md lists each page with its size, sha256, dependencies and summary. tasks/ holds task cards. tools/make_bundles.py concatenates whole pages; tools/unpack_reply.py applies a reply after checking checksums.
